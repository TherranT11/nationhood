Narrative Creator

A single-player story: a Conversation Sequence (Action narration + Speech from named characters, interleaved with optional flavor replies), then a Decision whose options carry effects. Triggers and effects use the shared builders; a decision option can Create a Story Bill or Unlock another Narrative via its effect category.

When Does This Trigger
Conversation Sequence plays in order · Action = italic narration · Speech = a named speaker, shown in quotes · the player clicks Continue through each
Decision the final reply · each option carries effects

Agenda Creator

A node in a progression tree. The tree builds itself from each agenda's Parent (children are derived — no separate edge list). Requirements, Hidden Requirements and Failures reuse the shared condition builder; Rewards reuse the shared effect builder.
