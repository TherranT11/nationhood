ℹ️ How Targets Work

Each option specifies a Target value (where the stat will settle, 0–10) and a Pull strength (how strongly this policy yanks the stat toward its target). Multiple policies may pull the same stat in different directions — the stat settles at the weighted equilibrium Σ(target × pull) / Σ(pull) and converges toward it gradually each tick.

🎚️ 2. Options

A multi-option policy is built from one or more options. Each option is a complete configuration — its own sector effects, costs, and stat effects — that nations can switch between via bills. A nation always has exactly one option active at a time.
